# SOAR & EDR Project

## Objective

This project aims to simulate a real-world SOC environment by integrating EDR (LimaCharlie) and SOAR (Tines). The goal is to automate the detection and response process for credential theft attempts (using LaZagne), reducing the mean time to respond (MTTR) and demonstrating how automation can assist SOC analysts in isolating threats efficiently.


### Technologies Used

- EDR: LimaCharlie (Endpoint Detection & Response).

- SOAR: Tines (Security Orchestration, Automation, and Response).

- Virtualization: Windows 10/11 VM (Target Machine).

- Tools: LaZagne (Credential Recovery Tool / Attack Simulation).

- Communication: Slack API & Email Integration.

- Analysis: MITRE ATT&CK Framework.

- Diagramming: Draw.io (Workflow & Architecture Design)

### Project Steps

1. **Logical Design & Workflow Architecting (Draw.io)**
   * Used **Draw.io** to create a logical blueprint of the SOC automation pipeline.
   * Mapped the data flow from the Windows endpoint (Telemetry) to the EDR (Detection), and finally to the SOAR platform (Response logic).

2. **Environment Setup & EDR Deployment**
   * Configured a Windows VM (target machine) and installed the **LimaCharlie EDR** sensor.
   * Verified the telemetry stream in the LimaCharlie dashboard to ensure real-time visibility of endpoint events.

3. **Attack Simulation (LaZagne & Credential Access)**
   * Simulated a "Credential Access" attack using the **LaZagne** tool to harvest passwords.
   * Monitored the raw telemetry to identify specific event markers (Process Creation, CLI arguments) generated by the tool.
  
<img width="712" height="546" alt="Screenshot 1447-07-11 at 11 51 00 AM" src="https://github.com/user-attachments/assets/b92facc5-41cc-4807-86bc-4d7c81dac6c3" />

4. **Detection Engineering (LimaCharlie D&R Rules)**
   * Authored a custom **D&R (Detection & Response) rule** in LimaCharlie to detect the execution of credential-dumping tools.
   * Mapped the detection logic to **MITRE ATT&CK Technique T1003 (OS Credential Dumping)** to align with industry standards.
  
<img width="1155" height="747" alt="Screenshot 1447-07-11 at 1 10 43 PM" src="https://github.com/user-attachments/assets/441e427c-5417-4afa-a4cb-d3496c158f99" />

5. **SOAR Integration & Notification Pipeline**
   * Integrated **LimaCharlie with Tines** using API keys and Webhooks to automate alert forwarding.
   * Configured automated notifications to **Slack and Email**, providing the analyst with essential alert metadata (Hostname, User, Process ID).
  
<img width="1109" height="423" alt="Screenshot 1447-07-11 at 1 14 10 PM" src="https://github.com/user-attachments/assets/37c52d6b-3114-4cb7-8ac1-0a1a98595f00" />

6. **Automated Response & Host Isolation**
   * Built an interactive **Tines Story** that includes a manual approval gate (Human-in-the-loop).
   * Configured the workflow to automatically **Isolate the Host** via the LimaCharlie API if the analyst confirms the threat, effectively stopping the attack in its tracks.
